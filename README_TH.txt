YT Helper — ต้นแบบเว็บแอปส่วนตัวสำหรับ iPhone/iPad

สิ่งที่ทำได้:
- เปิดเว็บไซต์ YouTube อย่างเป็นทางการ
- บันทึก/เปิด/ลบลิงก์ YouTube ในเบราว์เซอร์เครื่องนี้
- เพิ่มไอคอนบนหน้าจอหลักในรูปแบบเว็บแอปเมื่อโฮสต์ผ่าน HTTPS
- มี service worker สำหรับแคชหน้าแอปพื้นฐาน

สิ่งที่ยังทำไม่ได้:
- ไม่ได้บล็อกโฆษณา YouTube
- ไม่ได้ควบคุมแอป YouTube หรือเอาโฆษณาในวิดีโอออก
- ไม่ได้ติดตั้ง Safari Content Blocker (ส่วนขยายดังกล่าวต้องสร้างเป็นแอป iOS/ส่วนขยายด้วยเครื่องมือพัฒนา Apple)
- ยังไม่มีระบบซิงก์รายการข้ามอุปกรณ์

วิธีเปิดใช้จาก iPhone/iPad:
1. ต้องนำไฟล์ทั้งหมดขึ้นเว็บโฮสต์ที่ให้บริการ HTTPS (เช่น GitHub Pages) ก่อน เพราะ service worker ต้องใช้ secure context
2. เปิด URL ของเว็บไซต์นั้นใน Safari
3. แตะปุ่ม Share > Add to Home Screen
4. เปิด "Open as Web App" ถ้ามีตัวเลือก แล้วแตะ Add
5. เปิดไอคอน YT Helper จากหน้าจอหลัก

ข้อควรทราบ:
- ไฟล์ HTML อย่างเดียวที่เปิดจากแอป Files อาจใช้คุณสมบัติ PWA/service worker ไม่ครบ
- ข้อมูลรายการโปรดอยู่ใน localStorage ของเว็บไซต์นั้น หากล้างข้อมูลเว็บไซต์อาจสูญหาย
- อย่าใส่รหัสผ่านหรือข้อมูลส่วนตัวที่ละเอียดอ่อน
- การใช้ YouTube API ต้องทำตามนโยบายผู้พัฒนา YouTube และไม่ควรบล็อก/เปลี่ยนโฆษณาใน player

ไฟล์ในชุด:
- index.html: หน้าแอป
- manifest.webmanifest: ข้อมูลเว็บแอป
- sw.js: แคชหน้าแอปพื้นฐาน
- icon.svg: ไอคอน
